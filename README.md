# zodiac-astrology
Open source astrology software.

# AppImage version of Zodiac v0.7.1
- **Zodiac-v0.7.1-x86_64.AppImage** **[Download](https://github.com/Uthopik/zodiac-astrology/releases/download/v0.7.1/Zodiac-v0.7.1-x86_64.AppImage)**
- Right-click the **AppImage** file and grant permission via the **‘Permissions’** menu. Alternatively, in the terminal, grant permission using:

```bash
chmod +x ./Zodiac-v0.7.1-x86_64.AppImage
```
